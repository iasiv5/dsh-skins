# 显式保存模型取代自动落库

---
status: superseded by 0003-auto-save-on-change.md
date: 2026-08-31
---

1.0.0 设计 v2.3（§7.1）原定"预览 + 400ms 防抖自动落库"，关闭弹层即冲刷（Y6），并经四轮评审放行；发布前产品主人改判：编辑期间仅本地实时预览，点「保存」才写入配置存储并跨标签页同步，离开时有未保存修改需确认，「还原」丢弃预览，保存遇 409 冲突时保留预览并提示（Q37–Q41）。取舍的真实分歧是即时生效（参考实现 dsh-custom-skin 即如此）与显式提交的经典设置对话框心智，主人选择了后者。Y6 语义随之整体翻转为"关闭前确认"；预览层、修订号与 409 机制不变。

## Consequences

- 防抖自动冲刷与"关弹层即冲刷"路径删除，「保存/还原」成为唯一写入门户（三皮肤一致）。
- 图库资产操作（上传/单删/清空）不进保存制，即时生效——两制边界见 CONTEXT.md。
